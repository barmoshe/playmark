עם סאונד

לראות את זה

שני סרטונים קצרים, מוקלטים בתוך המשחק. השני הוא ה-Thornback מ-Wandcraft, למטה.

במשחק אמיתי

עיצוב מחדש של אויב ב-Wandcraft

Wandcraft הוא רוגלייט בפיקסל ארט. ה-Thornback שלו, אויב שמסתער עליך, נראה כמו כיכר לחם. סימון אחד, באמצע קרב:

Redesign the Thornback: make it look like a charging ram, with curled horns, thorns along its back and a glowing eye.
  1. המסגרת מצאה את הנוד. enemy.gd מסוג ram, יחד עם מצב הריצה: החדר, הגל, החיים והשרביט.
  2. Claude מצא את הארט. 16 שורות של פיקסלים ב-bestiary.gd, לפי חוקי הפלטה של המשחק.
  3. הציור מחדש. גב גבנוני, קוצים, קרן מסולסלת ועין זוהרת.
  4. בחזרה לקרב. "Fixed #1", והסמן נשאר במקום הסימון.

הסימון

מה הסוכן מקבל

כל סימון הוא תיקייה ב-.playmark/inbox, מחוץ ל-git כברירת מחדל. זה הסימון האמיתי מהסרטון.

  • annotated.pngהפריים, עם סיכות ממוספרות
  • clip_sheet.pngהשניות האחרונות, מהישן לחדש

בפנים

מה זה עושה

  • חזרה אחורה

    פספסת את הרגע? חוזרים עד חמש שניות אחורה ומסמנים את הפריים הנכון.

  • הקוד שמתחת לסיכה

    קוליידרים, נודים, סקריפטים ופקדי UI, לכל סיכה ומסגרת.

  • רוחות

    סימונים קודמים נשארים בעולם, במקום שבו נעשו. כתום זה פתוח, כחול זה תוקן.

  • שגיאות מסמנות את עצמן

    שגיאת סקריפט הופכת לסימון באג, עם הקליפ והלוג.

  • חזרה לסימון

    פותחים את המשחק בדיוק בנקודת הסימון. הסוכן יכול לצלם פריים ולבדוק את התיקון.

  • המצב של המשחק

    שורה אחת מוסיפה לכל סימון את השחקן, השלב או הציוד.

  • חד בכל רזולוציה

    שכבת הסימון היא חלון נפרד, אז גם משחקי פיקסל ארט נקראים טוב.

  • שיתוף בלי AI

    פקודה אחת הופכת את הסימונים לעמוד שכל אחד יכול לפתוח.

  • רק בבילדים של פיתוח

    שום דבר לא רץ בגרסת release, אלא אם מפעילים את זה.

מאפס

להתחיל איתו משחק חדש

פרויקט Godot ריק עם Playmark כבר בפנים: סצנה אחת שאפשר לשחק, AGENTS.md שמלמד את הלולאה, וקומיט ראשון. אומרים איזה משחק לבנות, משחקים כל צעד ומסמנים מה לא בסדר.

  1. /playmark:new star-dodger --name "Star Dodger"Claude Code
  2. Start a new Playmark game in star-dodgerCodex
  1. בונים צעד. מכניקה אחת, אויב אחד, מסך אחד.
  2. משחקים. CtrlShiftM על מה שלא בסדר.
  3. טריאז'. /playmark:triage, או מבקשים מ-Codex. הסוכן מתקן את מה שבוחרים.
  4. קומיט. ואז הצעד הבא.

למה

בניתי את Playmark תוך כדי עבודה על Wandcraft, רוגלייט שבו מתכנתים את השרביט. כשבדקתי את המשחק שלי, כל הזמן שמתי לב לדברים קטנים שלא רציתי לעצור בשבילם ולכתוב. עכשיו אני לוחץ על מקש, מצביע וממשיך לשחק.
